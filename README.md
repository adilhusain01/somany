## 🚀 How The Magic Works

Think of SoMany as your personal crypto butler:

1. **You make a wish** - Sign simple request saying "Move all my ETH to Somnia"
2. **Our butler network springs into action** - Relayer works across all chains simultaneously
3. **Assets get locked on source chains** - Your ETH gets safely secured on each network's Lock contracts
4. **Somnia receives the signal** - Our smart system detects all the locked assets and releases equivalent amount of wETH to user's address on Somnia network (Using Chainlink Oracles)
5. **You earn Somni STT tokens** - Get rewarded for every successful teleport!
